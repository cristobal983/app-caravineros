# Reglas de Proyecto y Preferencias del Usuario

## Idioma y Comunicación
- **Idioma obligatorio:** Toda la comunicación, explicaciones, preguntas al usuario y resúmenes de herramientas (`toolAction`, `toolSummary`) deben estar 100% en **español**.
- Cuando se soliciten permisos o confirmaciones, los mensajes deben ser claros y directos en español.

## Contexto de la Aplicación
- **Proyecto:** Aplicación móvil académica para la Escuela de Formación de Carabineros (ESFOCAR) - Asignatura DSY1105 (Duoc UC).
- **Tecnologías:** Kotlin, Jetpack Compose, Material Design 3, Arquitectura MVVM, Room SQLite (Offline-first).
- **Enfoque pedagógico:** Explicar los cambios paso a paso de forma didáctica para facilitar el aprendizaje y la defensa del proyecto ante el docente.
